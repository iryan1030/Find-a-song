# 1초 노래 맞히기

플레이리스트를 준비하고, 짧은 음악 구간을 들은 뒤 정답을 공개하는 웹 앱입니다.

## 실행

```bash
npm install
npm run dev
```

## 플레이리스트 준비

- 곡 제목, 가수, YouTube 링크, 재생 시작 시점을 직접 입력하거나 엑셀 파일에서 불러올 수 있습니다.
- 엑셀 파일은 첫 번째 시트에 `곡제목`, `가수`, `링크`, `재생 시작 시점 (초)` 열을 둡니다. 링크는 YouTube URL이 셀에 연결된 하이퍼링크여도 읽을 수 있습니다.
- 엑셀에서 불러오면 기존 플레이리스트를 교체하며, 곡이 등록되어 있을 때 먼저 확인합니다.
- 플레이리스트는 현재 브라우저에 저장됩니다.

## 게임 진행

문제 화면에서 1초, 2초, 3초 듣기를 선택하고 정답을 공개합니다. 정답 화면에서는 곡 제목과 가수, 가림막이 열린 YouTube 플레이어가 표시됩니다.

YouTube 영상의 외부 재생 허용 여부, 공개 상태, 브라우저 환경에 따라 일부 영상이 재생되지 않을 수 있습니다.
